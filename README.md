# ARJ Player

Android offline music-player project built with Kotlin and Jetpack Compose.

## Project structure
- `app/`: Android application module
- `app/src/main/java/`: Kotlin source code
- `app/src/main/res/`: Android resources

## Current status
The repository structure has been normalized. Playback service and audio-effects classes are currently placeholders and require implementation. See the project audit before treating this repository as a release-ready app.
